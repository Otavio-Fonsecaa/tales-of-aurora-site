# Tales of Aurora

Site oficial do projeto **Tales of Aurora**, um RPG de fantasia protagonizado por cachorros.

## Sobre o projeto

O Tales of Aurora apresenta a história, os personagens e os cenários do universo do jogo. A página também conta com menu lateral responsivo, sessão de personagens, carrossel de cenários e informações para apoiar a produção.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

Não é necessário instalar dependências.

1. Clone o repositório:

```bash
git clone https://github.com/Otavio-Fonsecaa/tales-of-aurora-site.git
```

2. Acesse a pasta do projeto.
3. Abra o arquivo `HTML/Inicio.html` no navegador.

Também é possível executar um servidor local, por exemplo:

```bash
python -m http.server 8000
```

Depois, acesse `http://localhost:8000/HTML/Inicio.html`.
